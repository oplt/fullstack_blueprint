```

```

**Previously used pattern:**

```
<label>
  <input
    checked={runForm.review_required}
    onChange={(event: any) =>
      setRunForm(current => ({
        ...current,
        review_required: event.target.checked,
      }))
    }
    type="checkbox"
    role="switch"
  />
</label>
```

**Recommended implementation:**

```
import { Switch } from "@/components/ui/switch";
import { Label } from "@/components/ui/label";

<div className="flex items-center gap-3">
  <Switch
    id="review-required"
    checked={runForm.review_required}
    onCheckedChange={(checked) =>
      setRunForm(current => ({
        ...current,
        review_required: checked,
      }))
    }
  />

  <Label htmlFor="review-required">
    Require human review
  </Label>
</div>
```

This also removes unnecessary `any` typing and provides an accessible name.

## **10. Final assessment**

The main problem is no longer Material UI itself. It is the **architectural and functional residue of the previous MUI migration**.

The highest-value improvements are:

- Restore missing content in former Chip implementations.
- Replace inaccessible or inconsistent switches and checkboxes.
- Consolidate custom components around existing shadcn primitives.
- Remove obsolete static styling patterns.
- Prevent the compatibility layer from returning.

Renaming Lucide aliases is considerably less important than fixing functionality and accessibility.

**Audit limitations:** I retrieved the complete repository file tree, inspected selected source files directly, checked the frontend lockfiles and analyzed historical migration commits. GitHub code search returned unreliable empty results, the bulk retrieval exceeded tool limits, and a full local clone was blocked by network restrictions. Consequently, this is a verified targeted audit, not an exhaustive line-by-line inspection of every source file. No files were modified, and build or runtime tests were not executed. The full-checkout verification commands above should be mandatory before declaring the migration complete.
