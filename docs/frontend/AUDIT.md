# Frontend audit

**Reference** `3271ffb`, audited 2026-11-24. The existing working copy had a user edit to `prompt.txt`. The analysis covers tracked frontend source, build/test configuration and relevant backend routes and schemas. See [architecture and functionality](ARCHITECTURE.md), [MUI coverage](COMPONENT_INVENTORY.md), [verification](TEST_BASELINE.md), and [build and browser measurements](PERFORMANCE_BASELINE.md).

| Finding | Evidence and impact | Phase |
| --- | --- | --- |
| Toolchain security and compatibility | Vite 5 with React plugin 4 and Vitest 3 builds successfully on Node 24. The full locked npm tree has 22 affected-package entries in the audit, including two critical dev/test entries and a high-severity production Zod entry. Node 22.13 support constrains some later tools, and the latest TypeScript registry version exceeds the current typescript-eslint peer range. | 1, 7, 16 |
| Styling ownership is divided | `DESIGN.md` describes a Linear marketing system with lavender `#5e6ad2`, `#010102` dark canvas and 480/768/1024/1280/1440 cutoffs. Runtime implements Tesla-named blue `#3E6AE1`, dark `#171A20`, a light default, and MUI cutoffs at 600/900/1200/1536. It declares Universal Sans with fallback and actually bundles only IBM Plex Mono. The PWA manifest hardcodes the dark brand color independently. | 2–4 |
| MUI crosses nearly every view boundary | 98 files directly import MUI, including eight test files. Global date and theme providers, CSS class selectors, MUI layout types and token helpers create coupling beyond JSX primitives. A shared component and phase-by-phase consumer migration is lower risk than page-wide rewrites. | 2–6 |
| Mobile and accessible name issues | Browser evidence shows document-width overflow on the 390 px dashboard and desktop sidebar list/name defects. Light-mode dashboard, profile and sidebar have measured contrast issues. The auth route has a heading/landmark defect. Details and unchecked interactions are in the test baseline. | 2, 4, 5, 6, 12 |
| Complex UI depends on behavior | `DataTable` owns selection, expansion, sticky controls, density and controlled/local operations. Clickable rows currently use a click handler and need an explicit keyboard interaction strategy. Shared tabs, tooltips, platform/editor and calendar state also require fixtures before exchanging primitives. The 12-month calendar uses a fixed three-column template, a separate responsive review target. | 4–6, 9, 12 |
| API mismatch can evade type checks | Manual DTOs and generic `apiFetch<T>` assertions mean the compiler cannot catch wire drift. Error extraction discards HTTP status and correlation metadata, and FastAPI 422 arrays do not become field-level messages. Item-only helpers can hide pagination metadata from callers. | 7 |
| Session ownership needs stronger coverage | The current credentialed transport uses one refresh promise and one JSON replay per request. One test covers concurrent refresh. Query cancellation is incomplete where wrappers never receive a signal. A failed logout exits before cache cleanup, and exhausted refresh is a thrown error without a single global session transition. Verify auth expiry and rejected logout behavior without retroactively changing baseline tests. | 7, 8, 16 |
| Optional visibility has multiple owners | Startup flags govern route registration. Platform metadata and an additional AI module guard govern AI availability. The shell, profile/admin tabs and route guards contain their own visibility decisions. Consolidate presentation policy while retaining server-side route and resource authorization. | 5, 8, 15 |
| AI workspace contract is finite | Existing AI Studio is an authoring/evaluation workspace. Agent/RAG expose status, JSON answers and citations, without a public event protocol found in the route/schema scan. The unused stream transport helper does not imply a live stream. Keep an integration seam and isolated fixtures while typed events, cancellation, reconnect and approval contracts are defined. | 7, 10, 11 |
| External link and output boundaries | Observability opens links with `noopener,noreferrer` and builds URLs from backend metadata. The backend producer checks HTTP(S). The generic frontend helper uses `new URL` and relies on that upstream restriction. Review both URL producers and consumers when extending link handling. The source search found no raw HTML rendering and no browser-storage auth tokens. AI output is rendered as React text or structured views today. | 10, 11, 16 |
| Entry bundle dominates cold navigation | The HTML entry/preload JS graph is 817,437 bytes, with the MUI chunk at 409,321 bytes. Routes already split, but shared MUI and the provider graph are eager. Base global CSS bundles multiple subsets of two mono weights and PWA artwork accounts for 367,884 bytes across two files. | 1, 2, 13 |
| PWA has a static precache baseline | Vite PWA uses `generateSW` and auto-update. There is a generated navigation fallback and no explicit API runtime cache. Preserve install/update behavior and verify logout cleanup and offline authed/API failure behavior against a production-like deployment. | 1, 13, 16 |
| Test scope and automation | Vitest/jsdom and Playwright provide existing behavior coverage. No tracked GitHub Actions workflow, Storybook, MSW or automated axe test integration was found. Browser and coverage results show gaps around optional features, real email and several UI mutations. | 12, 14, 16 |

## Preservation requirements

Keep URLs, cookie and CSRF contracts, refresh deduplication, roles and server access checks, feature discovery, settings tabs, file uploads, query invalidation, loading/error/empty states, and PWA behavior intact. Retain task workflow, project member boundaries, QR-based MFA, calendar date semantics, plan and webhook management, and AI/RAG data ownership. Use [the route and contract inventory](ARCHITECTURE.md#route-and-contract-inventory) as the verification list for each feature migration.
