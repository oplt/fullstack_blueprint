---
name: security-review
description: Perform a structured security review of a repository change.
---

Check access control, tenant leakage, auth/session/CSRF/CORS, injection, SSRF,
uploads, webhook signatures, secret exposure, DoS/rate limits, prompt injection,
tool authorization, resource budgets, and dependency risk. Record controls, residual
risk, tests, and deployment assumptions in the threat-model documentation.
